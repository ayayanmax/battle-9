# ⚡ 超・九九戦記 バトルナイン (BATTLE 9) - レベルアップエディション ⚡

小学二年生向けのカッコいいサイバーメカ風・九九練習ゲームです！
成績の自動集計、経験値（EXP）によるレベルアップ、称号獲得、そして多彩な敵ロボットが追加されました。

---

## 🎮 新機能・とくちょう

### 1. 成績集計 ＆ パイロットカード（セーブ機能）
- **挑戦回数・累計正答率・最高コンボ**を自動保存（次回起動時も記録が残ります）。
- 1の段〜9の段それぞれの**「段ごとの正解率」**も記録。苦手な段が一目でわかります。
- もし最初からやり直したい時は、画面右上の「⚙️」ボタンからデータリセットも可能です。

### 2. レベルアップ ＆ 称号コレクション機能
- 問題に正解したり、コンボを繋げたりすると**経験値（EXP）**を獲得！
- **称号コレクション一覧**：
  - タイトル画面上部の**「称号バッジ（一覧 🔍）」をクリック**すると、全12段階の称号リストがポップアップ！
  - **現在のレベル・現在の称号・獲得済みの称号・次の称号まであと何レベルか**が一目で分かります。
- **適正な成長バランス**：
  - 1問正解 ＝ 8 EXP、最大コンボボーナス ＋ パーフェクトボーナス
  - Lv.1 ➡️ Lv.2：10問クリア（約1回プレイ）でレベルアップ！
  - Lv.2 ➡️ Lv.3：約25問正解（2〜3回プレイ）でレベルアップ！
  - Lv.5以降：約50〜100問とじっくりやり込める設計になっています。
- 必要EXPがたまると**「LEVEL UP!!」のド派手な演出＆ファンファーレ**！

### 3. ゲーム効果音（SE）
- ビーム発射音、爆破音、コンボ上昇音、正解・不正解音、レベルアップ音、ファンファーレなどの迫力あるSEを内蔵。
- BGMは現在無音（集中して九九を解ける仕様）になっています。
- 画面右上の「音 ON/OFF」ボタンでいつでも効果音をミュート可能。
- レベルが上がるにつれて男児が大好きなカッコいい称号を獲得できます：
  - Lv.1: 九九ルーキー
  - Lv.2: アイアンスカウト
  - Lv.3: サイバーソルジャー
  - Lv.5: プラズマストライカー
  - Lv.8: バーストナイト
  - Lv.10: メガブレード戦士
  - Lv.15: シャドウアサシン
  - Lv.20: アストロコマンダー
  - Lv.30: 銀河バスター
  - Lv.40: 神速の九九マスター
  - Lv.50: 超次元九九ゴッド

### 3. 多彩な敵ロボット・ビジュアル
問題やレベル、出現パターンによって個性豊かなメカ敵が出現！
- 🛸 **スカウトドローン**（プロペラと鋭い単眼センサーを持つ偵察メカ）
- 🛡️ **アイアンタイタン**（肩に大型キャノンを積んだ重装甲二足歩行メカ）
- 🐺 **サイバービースト**（角と鋭い牙を持つ獣型戦闘メカ）
- 🐉 **サンダードラゴン**（光るメカ翼で飛来するプラズマ竜）
- 👑 **オメガエンペラー**（エネルギーコアと王冠を冠した皇帝型BOSSメカ）
